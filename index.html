Mi lista de regalos

Modo editar

Para añadir regalos desde aquí necesitas un token de GitHub. Se guarda solo en este navegador.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. En Repository access elige Only select repositories y marca lista.
  3. En Permissions → Repository permissions pon Contents: Read and write.
  4. Pulsa Generate token, copia el token y pégalo aquí.
