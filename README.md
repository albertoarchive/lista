# Lista de regalos · Navidad 2026

Cuatro listas (#alberto, #elena, #mama, #papa). Cualquiera con el enlace puede añadir, editar y quitar regalos.

- Web estática en GitHub Pages. Guarda los cambios en este repo con un token de GitHub limitado a este repo (`PARTS` en `index.html`, troceado para que GitHub no lo revoque).
- Añadir por enlace: se crea un pedido en `pedidos/` y la Acción `add.yml` (`scripts/add.py`) lee la web del producto y lo añade.
